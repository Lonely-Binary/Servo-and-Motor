# Servo and Motor

Example code for the Lonely Binary boards that drive servos and motors.

The tutorials, the handbooks, the 3D models and the drawings live on
[learn.lonelybinary.com](https://learn.lonelybinary.com). This repository
holds the sketches those pages point to, one directory per board:

```
boards/<board>/
  README.md    where the handbook is, and which sketch to start with
  examples/    code, one directory per sketch
  images/      renders of the assembled board
```
